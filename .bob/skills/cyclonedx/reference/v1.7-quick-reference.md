# CycloneDX v1.7 quick reference

Use this file **only** when the user explicitly asks for CycloneDX 1.7 (ECMA-424), for example to read or fix an existing 1.7 SBOM. For all new work, and for every LF AI & Data threat-modelling use case, use CycloneDX 2.0 (see [../SKILL.md](../SKILL.md)). The 1.7 JSON schema is not bundled with this skill; it is published at `https://cyclonedx.org/schema/bom-1.7.schema.json`.

## 1.7 vs 2.0: do not mix them

| Concept | 1.7 | 2.0 |
|---|---|---|
| Format marker | `"bomFormat": "CycloneDX"` | `"specFormat": "CycloneDX"` (`bomFormat` is rejected) |
| Version | `"specVersion": "1.7"` | `"specVersion": "2.0"` |
| Required top level | `bomFormat`, `specVersion` (`version` is recommended) | `specFormat`, `specVersion` |
| Element identifier | `bom-ref` | `refId` |
| Components | top-level `components[]` | `definitions.components[]` + `inventories[].components[{ref}]` |
| Services | top-level `services[]` | components of `type: "service"` |
| ML model details | `modelCard` | `modelProperties` (and `ai-ml` module) |
| Architecture / data flow | `services[].data[].flow`, limited | `blueprints[]` (zones, boundaries, actors, flows, relationships) |
| Threats | not modelled | `threats` module |

## Rules for 1.7 output

- Include `bomFormat: "CycloneDX"`, `specVersion: "1.7"`, `serialNumber` (`urn:uuid:…`), `version`, and `metadata.timestamp`.
- Give every component and service a unique `bom-ref`, and express the dependency graph in `dependencies[]` as `{ "ref", "dependsOn": [] }`.
- For a machine-learning model, use `type: "machine-learning-model"` with a `modelCard`, and pair datasets with components through `modelCard.modelParameters.datasets[].ref` (matching `bom-ref`).
- For CBOM, describe cryptographic assets with `type: "cryptographic-asset"` and `cryptoProperties`.
- Use registered `cdx:` property names from the [CycloneDX property taxonomy](https://github.com/CycloneDX/cyclonedx-property-taxonomy) (the AI/ML namespace is copied in [../cyclonedx-property-taxonomy/ai-ml.md](../cyclonedx-property-taxonomy/ai-ml.md)). Never invent names under `cdx:`.

## Minimal 1.7 example

```json
{
  "bomFormat": "CycloneDX",
  "specVersion": "1.7",
  "serialNumber": "urn:uuid:3e671687-395b-41f5-a30f-a58921a69b79",
  "version": 1,
  "metadata": {
    "timestamp": "2026-06-08T10:15:00Z",
    "component": { "bom-ref": "pkg:npm/my-application@1.0.0", "type": "application", "name": "My Application", "version": "1.0.0" }
  },
  "components": [
    {
      "bom-ref": "pkg:npm/lodash@4.17.21",
      "type": "library",
      "name": "lodash",
      "version": "4.17.21",
      "purl": "pkg:npm/lodash@4.17.21",
      "licenses": [ { "license": { "id": "MIT" } } ]
    }
  ],
  "dependencies": [
    { "ref": "pkg:npm/my-application@1.0.0", "dependsOn": ["pkg:npm/lodash@4.17.21"] },
    { "ref": "pkg:npm/lodash@4.17.21", "dependsOn": [] }
  ]
}
```

## Minimal 1.7 AI/ML-BOM component

```json
{
  "bom-ref": "component:ml-model/text-classifier@1.4.0",
  "type": "machine-learning-model",
  "name": "TextClassifierTransformer",
  "version": "1.4.0",
  "modelCard": {
    "modelParameters": {
      "approach": { "type": "supervised" },
      "task": "text-classification",
      "datasets": [ { "ref": "component:dataset/training-corpus-v2" } ]
    },
    "considerations": { "technicalLimitations": ["Maximum context window length capped at 512 tokens."] }
  }
}
```
